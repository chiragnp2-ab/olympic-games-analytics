# Olympic Games SQL Analysis

## 1. Project Overview
This folder contains SQL queries used to analyze historical Olympic Games data.

## 2. Database
PostgreSQL

## 3. Analysis Topics
- Total Olympic Games
- Total participating athletes
- Sports and events analysis
- Country-wise participation
- Gold, Silver and Bronze medal analysis
- Athlete performance
- Gender participation
- Historical Olympic trends

## 4. SQL Concepts
- SELECT and WHERE
- GROUP BY and ORDER BY
- JOINS
- Aggregate Functions
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
