# Olympic Games Analytics

## 1. Project Overview
This project analyzes historical Olympic Games data to identify trends and insights related to athletes, sports, events, countries, and medal achievements.

## 2. Project Objectives
- Analyze Olympic participation across different years.
- Identify countries with the highest medal counts.
- Analyze athlete participation by gender.
- Identify top-performing athletes.
- Compare Summer and Winter Olympic Games.
- Explore the historical evolution of Olympic sports and events.

## 3. Tools & Technologies
- Microsoft Excel
- PostgreSQL / SQL
- Power BI

## 4. Project Structure
- `olympic_analysis.sql` – SQL queries for Olympic data analysis.
- `README.md` – Project documentation.

## 5. Expected Outcomes
An interactive analytical dashboard and a comprehensive report presenting historical Olympic trends, medal performance, athlete participation, and key findings.
